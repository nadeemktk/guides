## Decisions made

1. **Next.js 16 vs 15:** Used 16.2.6 (latest stable as of build date). App Router API is identical for our purposes.
2. **shadcn/ui manual setup:** The shadcn CLI (`npx shadcn init`) requires live network access to `ui.shadcn.com` registry. Manually created `components.json` and authored core components (Button, Card, Input, Badge, Label, Separator). Will add more components as needed in Phase 1.
3. **Database types:** Manually written to match the migration schema. Should regenerate with `supabase gen types typescript` once the Supabase project is linked.
4. **Sentry integration:** `withSentryConfig` wraps `next.config.ts`. Two env vars needed beyond `SENTRY_DSN`: `SENTRY_ORG` and `SENTRY_PROJECT` (can add to .env.local).
5. **Stripe API version:** Used `2025-04-30.basil` (latest stable at build time).
6. **LLM model IDs:** Used `claude-sonnet-4-6` for Pro tier (current latest Sonnet), `claude-haiku-4-5-20251001` for standard tier — matches spec's intent.

## Deferred / open questions

1. **Supabase project:** Not linked yet — need `NEXT_PUBLIC_SUPABASE_URL` and keys before migrations can run. User must create a Supabase project.
2. **Stripe products:** Need to be created manually in Stripe Dashboard; price IDs must go into `.env.local`.
3. **Sentry project:** Needs `SENTRY_ORG` and `SENTRY_PROJECT` in addition to `SENTRY_DSN`. Added to .env.example.
4. **Amazon SP-API:** The spec notes this is hard; deferred until Shopify and WooCommerce are shipped (Phase 3).
5. **`supabase gen types`:** Once project is linked, run this to replace the manually-authored database types with auto-generated ones.
