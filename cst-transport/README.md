# CST Transport Manager
## City Star Transport Passengers LLC

> Enterprise-grade Windows Desktop Transport Management System

![CST Transport Manager](assets/banner.png)

---

## 🚀 Features

| Module | Description |
|--------|-------------|
| 🏠 **Dashboard** | Live KPI cards, revenue charts, top clients, vehicle performance |
| 🚗 **Daily Trips** | Full trip logging with payment toggle, driver/vehicle details, reminders |
| 📄 **Invoices** | Auto-numbered invoices, PDF print, SOA auto-update |
| 📒 **Statement of Account** | Client ledger with running balances |
| 🚌 **Fleet Management** | Vehicle profiles, document expiry alerts |
| 👨‍✈️ **Driver Management** | Driver profiles, license tracking |
| 💰 **Driver Salaries** | Monthly salary with overtime, deductions, printable slip |
| 🔧 **Vehicle Expenses** | Cost tracking by category with profitability analysis |
| 📊 **Reports** | Financial & trip reports, CSV export |
| 🤖 **CST CHAT INTELLIGENT** | AI business assistant powered by Claude |
| 🔔 **Payment Reminders** | Automated weekly/monthly reminders via email & in-app |
| 🛡️ **User Management** | RBAC with granular module permissions |
| 📋 **Activity Log** | Complete audit trail |
| ⚙️ **Settings** | Company info, system config, API keys |

---

## 🛠️ Tech Stack

- **Frontend:** React 18 + TypeScript + Tailwind CSS + Recharts
- **Desktop:** Electron 29
- **Database:** SQLite (better-sqlite3)
- **AI:** Anthropic Claude claude-opus-4-7
- **Email:** nodemailer
- **Auth:** bcryptjs
